# BioKey's baseline profile: code Android compiles ahead of time, so covers and lock screens don't
# run interpreted after an install or update. Google Play compiles it at install; other installs
# get it from ProfileInstaller on first launch, and it takes effect at the next background
# optimisation (usually while the phone is idle and charging). It covers the lock path of both
# engines (accessibility events, compatibility mode, the cover and what it draws with, the lock
# screen), the notification shield, and the session and settings state they read on every
# event. Compose and the other libraries bring their own profiles.
